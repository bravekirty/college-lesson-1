От прототипа до промышленной эксплуатации

компания разработала ИИ-систему для автоматической классификации обращений. Система получает сообщение и определяет категорию.

1. Техническая проблема
2. Оплата
3. Доставка
4. Другое

Сейчас существует только рабочий прототип. Руководство хочет внедрить систему в службу поддержки, задача - разработать план промышленного внедрения и сопровождекния.

- Создание API для удобного обращения к модели из бекенда сервиса поддержки
- Локальное тестирование API эндпоинтов
- Настройка доступа и конфигурационных файлов для развёртывания
- Развертывание сервиса на сервере
- Серверное тестирование API эндпоинтов
- Создание технической документации для разработчиков и сотрудников поддержки
- Обновление API сервиса поддержки (добавляем запрос в модель через API и обработка ответа)
- Обновление фронтенда (добавялем сортировку по категориям в админку службы поддержки)
- Тестирование обновлённой версии API сервиса поддержки
- Ручное тестирование фронтенда (проверяем что ничего не поехало после добавления категорий)
- Настройка мониторинга
- Чтение логов и выявление ошибок
- Хотфиксы частых проблем
