# Шпаргалка по дискретной математике

## 1. Множества и операции над ними

**Множество** — совокупность различимых объектов (элементов). Запись: $a \in A$ — принадлежит, $a \notin A$ — не принадлежит.

**Способы задания:** перечисление {1,2,3}; характеристическое свойство { $x \mid P(x)\$ }.

**Основные операции:**
| Операция | Обозначение | Определение |
|---|---|---|
| Объединение | $A \cup B$ | $x \in A$ или $x \in B$ |
| Пересечение | $A \cap B$ | $x \in A$ и $x \in B$ |
| Разность | $A \setminus B$ | $x \in A$ и $x \notin B$ |
| Симм. разность | $A \triangle B$ | $(A\setminus B)\cup(B\setminus A)$ |
| Дополнение | $\overline{A}$ | $U \setminus A$ |

U - Множество всех значений соблюдающих некое условие

**Мощность:** $|A|$ — число элементов.

## 2. Инъекция, сюръекция, биекция

Пусть $f: A \to B$.

- **Инъекция** У каждого A есть один B, у B может не быть несколько A
- **Сюръекция**: У каждого A есть один B, у B один или более А (не может не быть связи)
- **Биекция**: У каждого А есть B и наоборот, нет свободных или нескольких связей.

## 3. Числовые промежутки: включённые/невключённые границы

| Обозначение | Неравенство | Границы |
|---|---|---|
| $[a,b]$ | $a \le x \le b$ | обе включены |
| $(a,b)$ | $a < x < b$ | обе не включены |
| $[a,b)$ | $a \le x < b$ | левая вкл., правая нет |
| $(a,b]$ | $a < x \le b$ | левая нет, правая вкл. |
| $[a,+\infty)$ | $x \ge a$ | — |
| $(-\infty,b)$ | $x < b$ | — |

**Правило:** квадратная скобка = граница принадлежит; круглая = не принадлежит. $+\infty$ и $-\infty$ всегда с круглой скобкой.

## 4. Кортеж, декартово произведение

**Кортеж** — упорядоченный набор $(a_1, a_2, \dots, a_n)$; порядок важен, длина фиксирована. Два кортежа равны, если равны длины и все компоненты попарно.

**Декартово произведение:**
$$A \times B = \{(a,b) \mid a\in A,\ b\in B\}$$
Для $n$ множеств: $A_1\times\dots\times A_n$ — множество кортежей длины $n$.

**Мощность:** $|A\times B| = |A|\cdot|B|$; для $n$: $|A_1\times\dots\times A_n| = \prod |A_i|$.

**Свойства:** не коммутативно ($A\times B \neq B\times A$ в общем случае), дистрибутивно относительно $\cup,\cap$.
